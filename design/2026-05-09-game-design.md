## 一、游戏概念与愿景

### 1.1 一句话描述

一个日式新海诚画风的治愈系村庄生活模拟游戏，玩家以外来者身份定居于一个宁静的小村庄，体验日常生活中的小确幸与物哀之美。

### 1.2 核心感受

```
宁静 → 美与感动 → 探索
```

- **第一感受**：玩家进入游戏，首先感受到"啊，可以放松了"
- **第二感受**：视觉美到想截图，情感触动人心（并行）
- **第三感受**：自然产生探索欲，想走走看看

### 1.3 参考作品

| 作品 | 借鉴点 |
|------|--------|
| **江湖悠悠** | 水墨风田园生活，岁月静好的氛围 |
| **新海诚动画** | 云之彼岸、光影流动、细腻情感 |
| **旅行青蛙** | 佛系等待、随机惊喜、明信片风景 |
| **星露谷物语** | 农场经营、NPC日常互动、宁静感 |
| **风之谷·露天温泉** | 日式旅馆温暖氛围 |

### 1.4 视觉关键词

新海诚式光影、细腻渐变天空、治愈系色调、日常生活的诗意、自然与人的和谐、温暖木质建筑、季节流转感、乡愁与回归

## 二、核心玩法

### 2.1 游戏循环

**混合型**：挂机 + 主动互动

```
┌─────────────────────────────────────────────────┐
│                   村庄生态                        │
│  ┌─────────┐    ┌─────────┐    ┌─────────┐     │
│  │ 居民    │ ←→ │ 玩家    │ ←→ │ 访客    │     │
│  │ 自动生活│    │ 主动互动│    │ 随机/周期│     │
│  └─────────┘    └─────────┘    └─────────┘     │
└─────────────────────────────────────────────────┘
         ↑                    ↑
    季节/时间驱动          关系/任务
```

### 2.2 玩家视角

**外来者/定居者**

- 被村庄吸引而定居的外人
- 逐渐融入村庄的过程
- 有"发现"和"成长"的叙事弧线

### 2.3 核心交互

| 类型 | 内容 |
|------|------|
| **观察** | 挂机状态下村民自动生活，事件自然发生 |
| **对话** | 与居民/访客对话，建立关系 |
| **经营** | 整理家园、接待访客、布置空间 |
| **探索** | 探索村庄各个角落，发现小惊喜 |
| **日常活动** | 种田、做饭、冥想、养宠物（详见 2.4） |

### 2.4 日常活动系统

这些是玩家在云村可以参与的小游戏，每个都有简化的趣味性，同时融入整体治愈氛围：

| 活动 | 描述 | 可玩深度 |
|------|------|----------|
| **后院小田** | 种植蔬菜/水稻 + 果树 | 季节播种、浇水、收获、简单料理、果树养成 |
| **日常做饭** | 用收获的食材烹饪 | 食谱收集、简单烹饪、分享给村民 |
| **晨间冥想** | 在檐廊/庭院打坐 | 时间流逝感、季节风景、内心平静 |
| **养宠物** | 喂养村里的小动物 | 喂食、互动、观察它们的行为 |

#### 2.4.1 后院小田（含果树）

```
位置：云屋后院
规模：6-12 格小型田地 + 3-5 棵果树
作物周期：周为单位，春播秋收；果树月为单位
```

**玩法**：
- 翻土 → 播种 → 浇水 → 除草 → 收获
- 不同季节适合不同的作物
- 收获可存储或用于烹饪
- 果树栽种幼苗 → 培育 → 等待 → 采摘
- 不同果树在不同季节结果
- 果实可食用/送礼/加工

**简化设计**：不需要复杂灌溉系统，轻度浇水即可

#### 2.4.2 日常做饭

```
地点：云屋厨房
食材来源：自己种植 + 商店购买 + 居民赠送
```

**玩法**：
- 选择食材组合
- 简单翻炒/煮制动画
- 成品可自己吃或送给村民

**简化设计**：不是专业烹饪模拟，保持轻度休闲

#### 2.4.3 晨间冥想

```
地点：檐廊 / 庭院 / 神社 / 听雨林
触发：玩家主动选择
```

**玩法**：
- 选择场景坐下
- 画面停留，季节风景流动
- 时间推进，但玩家内心平静
- 可触发"顿悟"小事件

**情感意义**：给予玩家"停止忙碌、单纯存在"的空间

#### 2.4.4 养宠物

```
地点：云屋内/外
类型：猫咪、狗狗、鸟类、兔子等
来源：野生出现 / 居民赠送 / 发现
```

**玩法**：
- 每日喂食（简化的交互）
- 抚摸/互动
- 观察它们在云村的日常行为
- 它们有自己的"生活"，不是时刻需要玩家

**简化设计**：不是《星露谷》的复杂好感度，轻度互动即可

## 三、世界设定

**村庄名称**：云村

### 3.1 村庄生态

**云村** —— 一个坐落在山间的小村庄，常年被轻柔的云雾环绕

**规模**：小型，约 8-12 户固定居民

**环境元素**：
- 主角的住所「云屋」（已有「檐廊」设计）
- 村庄主道「云间小路」
- 小广场/「云隐神社」
- 几户邻居
- 村边的「听雨林」/小溪「落云涧」
- 远处的山峦「望云峰」

### 3.2 居民系统

**核心居民**：5-8 人

| 居民类型 | 特点 |
|----------|------|
| **邻居A** | 热心的中年妇人，常送自家种的菜 |
| **邻居B** | 沉默寡言的老人，喜欢在树下下棋 |
| **店主人** | 经营村里的小店，信息汇聚地 |
| **小孩** | 对外来者好奇，常来玩家家玩 |
| **其他** | 铁匠/花店/神社管理员等 |

**居民行为**：
- 有自己的日常作息
- 在村庄中自然移动
- 会触发随机小事件

### 3.3 访客系统

**访客类型**：

| 类型 | 来源 | 触发方式 |
|------|------|----------|
| **季节访客** | 远方返乡者/游客 | 季节触发 |
| **关系访客** | 居民的朋友/家人 | 好感度触发 |
| **自然访客** | 小动物/候鸟/流浪猫 | 随机事件 |
| **惊喜访客** | 意外到来的人 | 随机+剧情 |

## 四、事件系统

### 4.1 事件分类

| 类型 | 例子 | 情感色彩 |
|------|------|----------|
| **季节事件** | 春天樱花落、夏天萤火虫、秋天红叶、冬天初雪 | 温馨、期待 |
| **时间事件** | 日出/日落/黄昏/星空 | 宁静、诗意 |
| **关系事件** | 居民邀请朋友、远方家人归来、节日互赠 | 温暖、感动 |
| **自然事件** | 小动物来访、花悄悄开了、候鸟飞过 | 小小的喜悦 |
| **偶发事件** | 猫咪在廊下打盹、蝴蝶落在肩上 | 淡淡的哀伤/宁静 |
| **叙事事件** | 支线任务触发、特定角色剧情 | 深度体验 |

### 4.2 事件触发逻辑

```
时间系统
    │
    ├── 季节变化 ──→ 季节事件触发
    │
    ├── 时间段 ─────→ 日常事件（清晨/午后/黄昏/夜晚）
    │
    └── 特殊时间 ──→ 节日/节气事件

关系系统
    │
    └── 好感度阈值 ──→ 关系事件触发

随机系统
    │
    └── 环境随机 ──→ 自然事件/惊喜访客
```

### 4.3 事件优先级

1. **季节事件**：每个季节有 3-5 个标志性事件
2. **日常事件**：每天固定时段触发的小场景
3. **关系事件**：根据好感度自然解锁
4. **随机事件**：保持"惊喜感"，但频率控制

## 五、视觉与光影方案

### 5.1 技术方案

**手绘 2D 美术 + Godot 动态光影**

| 组件 | 技术实现 |
|------|----------|
| **场景美术** | 2D 手绘 Sprite / Texture，PNG 格式 |
| **角色美术** | 2D 手绘角色，PNG 序列帧动画 |
| **动态天空** | Godot Shader 实现流动云影 + 渐变色调 |
| **光影效果** | 2D Lighting + Shader 实现柔光、树影斑驳 |
| **季节变化** | Shader 渐变过渡 + 场景资源切换 |
| **时间系统** | 动态光源模拟日出/日落/黄昏 |

### 5.2 核心视觉目标

```
手绘场景 + 动态光影 = 既有温度又有呼吸感
```

- 静态的手绘角色/Sprite + 动态的环境光影
- 玩家看到的不只是"画"，而是"活着的场景"

### 5.3 视觉层次

```
Layer 4: 天空/远景（Shader 动态）
Layer 3: 背景建筑/树木（静态手绘 + 轻量动画）
Layer 2: 前景元素（可交互物体、光影粒子）
Layer 1: 玩家/角色（2D Sprite 动画）
Layer 0: UI 界面
```

### 5.4 关键视觉效果

| 效果 | 实现方式 |
|------|----------|
| **流动云影** | Shader: UV 动画 + 多层混合 |
| **阳光斑驳** | 粒子系统 + 透明度动画 |
| **日出/日落** | 动态调色 + 渐变 Shader |
| **四季色调** | 全局 Color correction Shader |
| **柔光效果** | 2D Light + 高斯模糊后处理 |
| **雨/雪** | 粒子系统 + 场景氛围 |

## 八、设计决策总结

| 决策点 | 选择 | 原因 |
|--------|------|------|
| 游戏循环 | 混合型 | 兼顾挂机与主动互动 |

### 9.1 关于「没有终点的故事线」

这很符合游戏的核心理念——生活没有终点，故事永远在继续。

**概念方向**：
- 玩家作为外来者融入云村的过程就是"故事"
- 没有明确的结局，但有阶段性的里程碑（如：获得了某位居民的信任、见证了某个季节的轮回）
- 叙事是"生活本身"，不是"任务完成"

**具体实现**（待进一步设计）：
- 融入度系统：随着时间推移，玩家在云村的存在感越来越强
- 四季循环叙事：每个季节有独立的小故事，整体构成"一年的故事"
- 关系演进：居民对玩家的态度随关系深度变化
- 访客故事：每个访客带来自己的小故事片段

### 9.2 商业化路径

```
Phase 1: Steam 买断
├── 基础游戏本体
├── 核心场景/居民/事件
└── 四季完整循环

Phase 2: 资源包扩展
├── 新场景（温泉/山顶/洞穴...）
├── 新居民/NPC
├── 新物件/家具

Phase 3: 联网社交
├── 云村拜访（玩家之间）
├── 访客系统扩展
└── 社区功能
```
