# 11 — 验收检查清单

版本：v1.0  
用途：检查 Codex 实现、美术资产、内容数据是否符合项目方向。

---

## 1. 最高级检查

| 检查项 | 必须通过 |
|---|---|
| 无战斗 | 没有战斗、伤害、怪物、武器、血量系统 |
| 治愈基调 | 文案、UI、美术不偏暗黑或高压 |
| 生活循环 | 起床、日常、睡觉、跨日可运行 |
| 村庄恢复 | 至少有一个修复目标可完成 |
| 关系系统 | 至少有 NPC 对话和好感变化 |
| 数据驱动 | 物品、作物、NPC 不硬编码为唯一来源 |
| 美术统一 | 资产符合低饱和、绘本感、3/4 视角 |

---

## 2. 代码检查

- [ ] 项目可打开。
- [ ] 主场景可运行。
- [ ] 无阻断报错。
- [ ] Autoload 正确注册。
- [ ] GDScript 尽量有类型标注。
- [ ] 系统没有强耦合循环引用。
- [ ] 数据加载失败时有清楚错误提示。
- [ ] 保存文件缺字段时不会崩溃。
- [ ] 新增系统没有引入 combat/weapon/hp/damage/monster 字段。

---

## 3. 时间与天气检查

- [ ] 时间会流逝。
- [ ] HUD 显示日期、季节、天气。
- [ ] 睡觉进入下一天。
- [ ] 第二天天气会变化。
- [ ] 雨天影响农田浇水。
- [ ] 跨日会重置每日对话和送礼计数。

---

## 4. 农田检查

- [ ] 地块可开垦。
- [ ] 可播种。
- [ ] 可浇水。
- [ ] 作物跨日成长。
- [ ] 成熟后可收获。
- [ ] 收获物进入背包。
- [ ] 雨天自动浇水。
- [ ] 不合季节作物有合理处理。

---

## 5. 背包与物品检查

- [ ] 物品可堆叠。
- [ ] 物品名称和描述显示正确。
- [ ] 种子、作物、材料分类正确。
- [ ] 关键物品不能误卖或丢弃。
- [ ] 背包变化会刷新 UI。

---

## 6. NPC 与对话检查

- [ ] NPC 可交互。
- [ ] 对话框显示 NPC 名称。
- [ ] 对话受季节/天气/好感影响。
- [ ] 每日首次对话增加好感。
- [ ] 送礼改变好感。
- [ ] NPC 文案不只是功能提示。

---

## 7. 修复系统检查

- [ ] 修复目标显示需求。
- [ ] 材料不足不能修复。
- [ ] 材料足够可修复。
- [ ] 修复会扣资源。
- [ ] 修复后视觉变化。
- [ ] 修复后解锁功能/传闻/区域。
- [ ] 修复状态可保存读取。

---

## 8. 美术资产检查

- [ ] 命名符合 `docs/05_ART_ASSET_BIBLE.md`。
- [ ] 透明背景正确。
- [ ] 3/4 俯视视角一致。
- [ ] 颜色低饱和且温暖。
- [ ] 缩小后可读。
- [ ] 角色轮廓清晰。
- [ ] 可交互物比背景更醒目。
- [ ] 没有武器、怪物、战斗 UI。
- [ ] 没有直接复制具体游戏或动画风格。

---

## 9. UI 检查

- [ ] UI 字体清楚。
- [ ] 对话框不挡住关键交互。
- [ ] 背包操作清晰。
- [ ] HUD 信息足够但不拥挤。
- [ ] UI 风格为纸张/木牌/手账感。
- [ ] 不使用科幻、暗黑、硬核 RPG 风格。

---

## 10. 垂直切片完成标准

以下流程必须可完整执行：

```text
启动游戏
→ 主角在老屋或庭院醒来
→ 查看天气/信箱
→ 种下种子
→ 浇水
→ 去村道与 NPC 对话
→ 采集材料
→ 回家睡觉
→ 第二天作物成长
→ 收获作物
→ 送礼给 NPC
→ 修复旧水井
→ 触发关于铃声的传闻
→ 保存
→ 退出重进
→ 状态正确恢复
```

---

## 11. 偏离检查

出现以下情况必须回滚或重做：

- 添加战斗。
- 美术变成写实/暗黑/高饱和。
- 主角变成战斗或幻想角色。
- 复杂系统导致 MVP 不能运行。
- 任务文案像 RPG 打怪任务。
- NPC 只剩商店功能，没有生活感。
- 系统硬编码导致后续无法扩展。
