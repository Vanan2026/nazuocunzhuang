# 04 — 美术设计圣经：Art Direction Bible

版本：v1.0  
美术方向：日式乡村治愈绘本风的模块化 2D 游戏资产体系。

---

## 1. 总体美术定位

《那座村庄》采用温暖低饱和的日式乡村绘本风格。场景保留手绘氛围，角色与可交互物件采用更简化、更清晰、更适合动画的游戏化造型。画面目标不是“像一张复杂插画”，而是“玩家在实际操作中感到舒服、清楚、温柔”。

### 1.1 一句话风格

> 温暖、低饱和、轻手绘质感、固定 3/4 俯视视角、模块化 2D、清晰轮廓、慢生活乡村氛围。

### 1.2 关键词

```text
cozy
storybook
soft hand-painted texture
Japanese countryside
warm low saturation
clear silhouette
game-readable assets
modular 2D
top-down 3/4 view
quiet village life
```

### 1.3 禁止关键词

```text
combat fantasy
hardcore survival
dark horror
photorealistic
high contrast neon
complex anime illustration
heavy oil painting
hyper detailed line art
copying any named game or animation style
```

## 2. 镜头与视角

### 2.1 视角

- 固定 3/4 俯视。
- 角色可四方向或八方向移动。
- 建筑、家具、农田、道路统一使用同一透视基准。
- 不使用横版平台视角。
- 不使用第一人称或第三人称写实镜头。

### 2.2 画面比例

- 目标平台：PC。
- 基准分辨率：1920x1080。
- UI 适配 16:9，后续兼容 16:10。
- 游戏内相机保持稳定，不频繁旋转。

### 2.3 可读性规则

在游戏实际缩放下必须能看清：

- 主角朝向。
- NPC 身份差异。
- 可交互物轮廓。
- 作物成长阶段。
- 门、路、桥、台阶等可通行信息。

## 3. 色彩系统

### 3.1 总体配色

画面应偏温暖、低饱和、轻微灰度。不要过度鲜艳。

核心色系：

| 用途 | 色彩 | 示例 HEX |
|---|---|---|
| 米白纸感 | 背景、UI 纸张 | #F3E7D1 |
| 暖木色 | 屋梁、家具、木牌 | #A9794B |
| 深木色 | 描边、暗部 | #5A3B2A |
| 草绿 | 春夏草地 | #8FAF6A |
| 深墨绿 | 山林暗部 | #3F5F45 |
| 柿子橙 | 标志性点缀 | #D9823B |
| 天空淡蓝 | 清晨、UI 点缀 | #A9C9D8 |
| 樱花粉 | 春季点缀 | #E8B7B4 |
| 暖灰 | 石头、阴影 | #9A9285 |
| 夜色蓝灰 | 夜晚 | #39475B |

### 3.2 主角识别色

主角必须有稳定识别色，建议：

- 米白上衣。
- 草绿色或浅蓝围裙。
- 暖棕鞋/包。
- 小面积柿子橙或红棕发绳。

### 3.3 色彩禁忌

- 大面积纯黑。
- 大面积荧光绿、荧光紫、霓虹蓝。
- 角色和背景同明度导致混在一起。
- 阴影过冷过重。

## 4. 线条与描边

### 4.1 描边原则

- 使用柔和深棕或暖灰描边，不用纯黑硬描边。
- 背景描边较弱，交互物描边较清晰。
- 角色外轮廓比内细节更重要。
- 线条不要太细碎，缩小后不能糊成噪点。

### 4.2 线条层级

| 层级 | 描边强度 |
|---|---|
| 背景远景 | 很弱或无描边 |
| 地面/墙面 | 弱描边 |
| 可交互物 | 中描边 |
| 角色/NPC | 中到强描边 |
| UI 图标 | 清晰描边 |

---

## 5. 光影与材质

### 5.1 光影

- 使用软阴影。
- 一般物体只需要 1 层阴影。
- 不做高复杂厚涂体积光。
- 允许少量阳光光斑、树影、窗影。

### 5.2 材质

材质应有轻微手绘纸感或笔触，但不能盖过形状可读性。

推荐：

- 木头有简化纹理。
- 石头有少量斑点。
- 草地有稀疏笔触。
- UI 纸张有轻微颗粒。

不推荐：

- 高噪点。
- 复杂照片纹理。
- 过度水彩扩散。
- 每个小物体都画满细节。

## 6. 角色设计规范

### 6.1 角色比例

| 项目 | 规范 |
|---|---|
| 头身比 | 3.5 到 4 头身 |
| 头部 | 稍大，便于识别 |
| 手脚 | 圆润简化 |
| 五官 | 小而清楚 |
| 衣服 | 大色块，少褶皱 |
| 轮廓 | 一眼能识别身份 |

### 6.2 主角方向

主角应是“回到乡村生活的人”，不是战斗少女、偶像或冒险英雄。

建议造型：

- 短发、低马尾或半扎发。
- 米白宽松衬衫。
- 浅蓝/草绿围裙。
- 暖棕布鞋。
- 小布包或草帽。
- 一个稳定小点缀：发绳、胸针、包带。

### 6.3 NPC 设计

NPC 要通过轮廓、颜色和小物件区分职业与性格。

| 职业 | 视觉锚点 |
|---|---|
| 杂货店主 | 围裙、账本、小铅笔 |
| 木匠 | 工装背带、卷尺、木屑 |
| 邮差 | 布邮包、帽子、信封色点缀 |
| 医生 | 暖白外套、草药包 |
| 神社看守 | 简化传统服饰、铃、绳结 |
| 小孩 | 书包、昆虫网、帽子 |

## 7. 场景设计规范

### 7.1 场景层级

| 层级 | 作用 | 画法 |
|---|---|---|
| 背景层 | 氛围 | 低对比、低细节 |
| 结构层 | 房屋、道路、地形 | 清晰但不抢角色 |
| 交互层 | 门、信箱、作物、工具 | 轮廓更清楚 |
| 氛围层 | 落叶、光斑、炊烟、风铃 | 轻动态，非必要交互 |

### 7.2 场景标志物

《那座村庄》应拥有一批强记忆点：

- 主角家缘侧。
- 柿子树。
- 风铃。
- 旧水井。
- 木制信箱。
- 村口小桥。
- 杂货店门口布帘。
- 后山石阶。
- 神社旧铃。
- 夏夜灯笼。

## 8. UI 设计规范

### 8.1 UI 气质

UI 应像手账、木牌、便签、村庄公告板，而不是现代科幻面板。

### 8.2 UI 元素

| UI | 风格 |
|---|---|
| 背包 | 木框+纸张底 |
| 日历 | 挂历或手账页 |
| 任务日志 | 便签/笔记本 |
| 对话框 | 米白纸张+暖木边 |
| 好感度 | 小叶子/小花/心形，需低调 |
| 天气 | 简化手绘图标 |

### 8.3 字体原则

- 中文要清晰易读。
- 标题可用圆润手写感字体，但正文必须可读。
- 不要使用过度花哨字体。
- UI 字号不能太小。

---

## 9. 动画规范

### 9.1 角色动画

MVP 必须有：

- idle。
- walk 四方向。
- water 浇水。
- pick_up 拾取。
- interact 交互。

正式版扩展：

- run。
- sit。
- cook。
- fish。
- plant。
- harvest。
- pet_animal。
- wave。

### 9.2 动画气质

- 动作慢一点、圆润一点。
- 不要快速战斗感。
- 工具动作要有可读预备帧。
- 循环动画要安静自然。

### 9.3 场景动效

- 风铃轻摆。
- 炊烟慢慢上升。
- 叶子偶尔飘落。
- 水面轻微闪动。
- 夜晚灯光轻微跳动。

## 10. 四季视觉规范

| 季节 | 主色 | 点缀 | 动效 |
|---|---|---|---|
| 春 | 新绿、米白 | 樱花粉 | 花瓣飘落 |
| 夏 | 浓绿、淡蓝 | 西瓜红、灯笼橙 | 蝉、强日光、萤火 |
| 秋 | 金黄、柿子橙 | 枫叶红 | 落叶、丰收筐 |
| 冬 | 雪白、蓝灰 | 暖灯黄 | 雪、炉火、白雾 |

---

## 11. 美术验收标准

每个资产必须满足：

- 缩小到游戏尺寸仍可识别。
- 透明背景正确。
- 命名符合规范。
- 风格不偏向写实、暗黑、战斗幻想。
- 能融入固定 3/4 俯视场景。
- 交互物比纯背景物更清晰。
- 不直接模仿任何具体版权作品。

---

## 12. 视觉反例

以下都不符合项目：

- 过度精致立绘，无法动画。
- 写实 3D 模型截图。
- 高饱和赛博 UI。
- 像战斗 RPG 的武器图标。
- 暗黑恐怖神社。
- 每个草丛都细节过多导致读不清。
- 主角过度美少女化、偶像化、幻想服装化。
