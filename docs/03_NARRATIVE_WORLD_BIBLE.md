# 03 — 叙事与世界观圣经

版本：v1.0  
用途：定义故事气质、村庄秘密、NPC 设计方向、对话口吻和结局结构。

---

## 1. 世界观基调

《那座村庄》的世界不是奇幻冒险世界，而是带有轻微神秘感的乡村生活世界。

它的关键词是：

```text
回家、旧屋、风铃、柿子树、雨声、信、村路、神社、夏夜、旧照片、未说完的话
```

玩家一开始以为这里只是一座普通村庄，随着生活推进，逐渐发现：

- 村民对某些旧事避而不谈。
- 老屋里有不属于玩家记忆的物件。
- 神社铃声会在无风的夜里响起。
- 柿子树似乎每年重复某个日期的变化。
- 村庄的“恢复”不仅是建筑恢复，也是在恢复被遗忘的关系。

---

## 2. 故事主题

### 2.1 主主题

> 人不是通过打败什么来改变世界，而是通过照顾、修复、理解和留下来，让一个地方重新活起来。

### 2.2 副主题

- 城市疲惫与乡村慢生活。
- 家族记忆与未完成的承诺。
- 自然不是资源仓库，而是共同生活的邻居。
- 人和地方互相记住彼此。
- 离开也是成长，留下也是选择。

---

## 3. 主角设定

### 3.1 基础设定

主角是一个离开村庄多年后回来的年轻人。性别可由玩家选择或先默认女性主角。她继承或暂住一间旧屋，最初只是想整理房子，后来被村庄生活慢慢留下。

### 3.2 主角性格口径

主角不是天选之人，也不是冒险英雄。

她应表现为：

- 安静。
- 温和。
- 有一点疲惫。
- 愿意听别人说话。
- 对旧事有模糊记忆。
- 通过行动而不是宣言改变村庄。

### 3.3 主角成长

主角的成长不是战力成长，而是：

| 阶段 | 表现 |
|---|---|
| 陌生 | 只是在村里临时住下 |
| 适应 | 学会种田、做饭、拜访村民 |
| 连接 | 参与村庄修复、帮助 NPC |
| 记起 | 从旧物和事件中拼出过去 |
| 选择 | 决定离开、留下或唤醒村庄 |

---

## 4. 村庄设定

### 4.1 村庄整体

这是一座逐渐被年轻人离开、被树木和时间包围的旧村庄。它没有完全荒废，但很多设施已经停止使用。

村庄状态：

- 杂货店还在开，但货架很空。
- 老桥断了一半。
- 神社很久没人认真打扫。
- 果园还有几棵树活着。
- 邮差仍然按时送信。
- 孩子越来越少。
- 有些房子晚上不点灯。

### 4.2 主要地点

| 地点 | 表层作用 | 深层作用 |
|---|---|---|
| 主角老屋 | 家园、存档、料理、布置 | 家族记忆与旧物线索 |
| 庭院 | 种田、树、宠物、手作 | 柿子树与循环线索 |
| 村道 | NPC 日常、传闻 | 村民关系网 |
| 杂货店 | 买种子、基础物资 | 店主家庭支线 |
| 老桥 | 地图门槛 | 村庄曾经断开的关系 |
| 后山 | 采集、鱼、鸟、蘑菇 | 自然失衡线索 |
| 神社 | 供奉、节日 | 主线秘密核心 |
| 果园 | 果树与秋季玩法 | 前代人的约定 |
| 溪流 | 钓鱼、浇水、夏季活动 | 水路记忆 |

## 5. NPC 设计原则

### 5.1 NPC 不是功能标签

即使 NPC 有功能，也必须有生活状态。

错误写法：

```text
杂货店老板：卖东西。
```

正确写法：

```text
葵是杂货店店主。她很会记账，但最近进货越来越少。她嘴上说村里这样也挺好，其实担心店会在冬天前关门。
```

### 5.2 NPC 分类

| 类型 | 数量建议 | 作用 |
|---|---|---|
| 功能型 NPC | 5-8 | 商店、木匠、医生、邮差等 |
| 情感型 NPC | 6-10 | 主要关系支线 |
| 季节型 NPC | 4-6 | 节日、旅行商人、候鸟观察者 |
| 神秘型 NPC | 2-4 | 神社、梦、旧记忆 |
| 儿童/老人 | 4-6 | 增加村庄生活层次 |

## 7. 主线结构

### 7.1 第一幕：回到村庄

目标：让玩家熟悉生活循环。

内容：

- 主角回到旧屋。
- 学会种田、采集、送礼。
- 认识 4 到 6 个 NPC。
- 第一次听到无风铃声。
- 修复第一个设施：旧水井。

### 7.2 第二幕：村庄恢复

目标：让玩家通过修复和关系看到村庄变化。

内容：

- 修复老桥。
- 集市重新开放。
- NPC 支线逐渐交叉。
- 老屋储物间发现旧照片。
- 后山出现不正常的季节迹象。

### 7.3 第三幕：被记住的地方

目标：揭示温柔秘密。

内容：

- 神社旧铃被修复。
- 村民记忆产生微妙矛盾。
- 主角发现自己家与村庄循环有关。
- 玩家选择如何面对村庄。

---

## 8. 结局结构

### 8.1 结局 A：留在村庄

玩家选择接受村庄缓慢的循环，但让它变得更温柔。村庄继续存在，老屋完全修好，主角成为新一代村民。

### 8.2 结局 B：离开村庄

玩家整理完旧事，选择回到城市或新的生活。村庄没有被抛弃，玩家带着记忆离开。

### 8.3 结局 C：唤醒村庄

玩家通过修复、关系和神社线索，让村庄从重复的旧时间中醒来。自然恢复流动，村庄进入新的四季。

## 10. 对话写作规范

### 10.1 语气

- 平实。
- 有生活细节。
- 少解释世界观。
- 留一点空白。
- 不使用过度网络化语言。

### 10.2 示例

普通天气：

```text
“今天风小，晒衣服正好。你要是路过河边，帮我看看桥那头的草是不是又长高了。”
```

雨天：

```text
“雨下成这样，店里大概没什么客人。不过萝卜种子今天应该会便宜一点。”
```

神秘线索：

```text
“你听见铃声了？那就别急着问。村里有些声音，要等人住久了才听得懂。”
```

### 10.3 禁止口吻

- 过度中二。
- 解释型旁白太多。
- NPC 只像任务发布器。
- 直接把主线秘密说出来。
- 把村庄写成恐怖片。

## 11. 任务文案规范

任务标题要生活化：

| 不推荐 | 推荐 |
|---|---|
| 主线任务 01：修复水井 | 让水井重新有水声 |
| NPC 好感任务 | 葵的进货清单 |
| 神社谜题 | 无风的铃声 |
| 解锁地图 | 桥那边的路 |

---

## 12. 隐藏线索表达方式

隐藏秘密不通过恐怖惊吓表现，而通过重复、错位和记忆表现：

- 同一句话在不同季节由不同 NPC 说出。
- 旧照片中的房子和现在不完全一致。
- 信的日期比当前年份早很多。
- 某个 NPC 记得玩家做过但玩家没经历过的事。
- 柿子树在冬天也结出一个果子。

---

## 13. 宠物与动物

动物是陪伴和发现系统的一部分。

| 动物 | 功能 |
|---|---|
| 猫 | 在村里游走，带回旧物或小礼物 |
| 狗 | 陪玩家去后山，发现隐藏路标 |
| 鸟 | 季节图鉴，提示天气和地点变化 |
| 狐狸 | 夜晚远处出现，引导神秘事件 |

动物不作为战斗单位，不攻击，不受伤害。
