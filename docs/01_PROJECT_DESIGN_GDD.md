# 01 — 《那座村庄》项目设计文档 GDD

版本：v1.0  
用途：给产品设计、程序开发、美术生产、Codex 任务拆解提供统一设计依据。

---

## 1. 游戏定位

### 1.1 一句话定位

《那座村庄》是一款无战斗的治愈系乡村生活模拟游戏。玩家回到一座被树木与旧记忆包围的村庄，在修复老屋、经营庭院、种植作物、料理、拜访村民、参加季节活动的日常中，让村庄重新恢复生机，并逐渐发现隐藏在自然和时间里的温柔秘密。

### 1.2 类型标签

```text
Cozy Game
Life Simulation
Farming Lite
Village Restoration
Relationship Simulation
Seasonal Exploration
Storybook 2D
No Combat
```

### 1.3 玩家幻想

玩家幻想不是“变强”，而是：

- 回到一个慢下来的地方。
- 拥有一间可修复、可布置、可生活的老屋。
- 每天醒来有小事可做，但没有强迫压力。
- 村民慢慢认识你、信任你、向你说出过去。
- 你种下的树、修好的桥、做过的饭，会改变村庄。
- 普通日常背后藏着一点点秘密。

---

## 2. 设计支柱

| 支柱 | 说明 | 可验收表现 |
|---|---|---|
| 无战斗慢生活 | 不通过战斗制造压力 | 没有血量、怪物、武器、击杀系统 |
| 每天都有小目标 | 玩家自然产生“再过一天”的冲动 | 每天有天气、传闻、作物、NPC、事件变化 |
| 修复驱动成长 | 进度来自恢复家与村庄 | 老屋、桥、集市、神社、果园逐步恢复 |
| 人际关系长线 | NPC 是内容核心之一 | 作息、好感、礼物、支线、记忆事件 |
| 四季带来新鲜感 | 复用地图但改变资源与气氛 | 春夏秋冬有独立作物、节日、视觉、鱼虫 |
| 温柔神秘感 | 深度来自发现，不来自危险 | 旧物、传闻、神社、梦、重复出现的事件 |

## 3. 核心循环

### 3.1 每日循环

```text
起床
↓
查看天气 / 日历 / 信箱 / 今日传闻
↓
选择今日目标
  - 种田
  - 采集
  - 钓鱼
  - 料理
  - 拜访 NPC
  - 修复设施
  - 探索村庄
↓
获得资源 / 金钱 / 好感 / 线索 / 村庄贡献
↓
回家整理、制作、送礼、供奉或布置
↓
夜晚事件或梦境片段
↓
睡觉进入下一天
```

### 3.2 中期循环

```text
稳定产出作物
→ 用资源修复设施
→ 解锁新地点和新 NPC
→ 获得新作物、料理、工具
→ 推进关系与剧情
→ 触发季节活动
→ 扩展家园与村庄
```

### 3.3 长线循环

```text
四季轮转
→ 村庄状态变化
→ NPC 支线完成
→ 图鉴逐步填满
→ 旧物线索汇集
→ 发现自然与时间的秘密
→ 做出结局选择
```

## 4. 玩家目标结构

### 4.1 短期目标：1 到 15 分钟

- 浇水。
- 收菜。
- 送一份礼物。
- 钓一条鱼。
- 捡到一枚旧纽扣。
- 把信送给邻居。
- 做一份饭。
- 买一包种子。

### 4.2 中期目标：1 到 5 个游戏日

- 修好水井。
- 解锁后山小路。
- 达成某位 NPC 的 2 心事件。
- 凑齐厨房升级材料。
- 种出第一批秋季果树。
- 参加夏夜祭。

### 4.3 长期目标：一整个季节以上

- 修复老屋所有房间。
- 恢复村庄集市。
- 完成 8 到 12 名核心 NPC 的支线。
- 收集完整季节图鉴。
- 找齐神社旧铃的碎片。
- 解锁三个主结局。

## 5. 范围定义

### 5.1 MVP 范围

MVP 应只做一个可玩的垂直切片，不追求全内容。

| 模块 | MVP 内容 |
|---|---|
| 时间 | 1 个季节，28 天 |
| 地图 | 主角家、庭院、村道、杂货店、2 间邻居家、后山入口 |
| 农田 | 8 到 12 种作物，基础浇水与收获 |
| NPC | 6 名 NPC，有作息、对话、礼物、2 心事件 |
| 料理 | 10 个基础料理 |
| 修复 | 老屋厨房、水井、村口小桥 3 个修复目标 |
| 事件 | 10 个日常事件，2 个季节事件，1 个神秘事件 |
| UI | 时间、日期、天气、背包、对话、日历、任务日志 |
| 保存 | 读档、存档、跨日保存 |

### 5.2 正式版范围

| 模块 | 正式版目标 |
|---|---|
| 季节 | 春夏秋冬完整循环 |
| NPC | 16 到 24 名有命名 NPC |
| 地图 | 主角家、村庄、果园、后山、溪流、神社、集市、温泉路口 |
| 作物 | 40+ 作物/果树/采集物 |
| 料理 | 80+ 料理 |
| 图鉴 | 作物、鱼、昆虫、鸟、料理、旧物、传闻 |
| 结局 | 3 个主结局 + 若干隐藏尾声 |

## 6. 主要游戏系统概览

### 6.1 时间系统

- 一天分为早晨、上午、下午、傍晚、夜晚。
- 时间流逝要慢，允许玩家悠闲游玩。
- 到深夜会提醒玩家回家，不做死亡惩罚。
- 睡觉结算作物、关系事件、天气、邮件。

### 6.2 农田系统

- 种植、浇水、等待、收获。
- 不做复杂肥料经济，先保留基础肥料作为正式版扩展。
- 作物应服务料理、送礼、修复、节日委托。

### 6.3 采集系统

- 每日刷新少量野花、蘑菇、草药、树枝、石子。
- 刷新受季节、天气、村庄状态影响。
- 采集物不只是卖钱，也用于料理、礼物、修复、供奉。

### 6.4 钓鱼系统

- 推荐低压力小游戏。
- 鱼类受地点、时间、天气、季节影响。
- 不要求高操作惩罚，失败只损失少量时间。

### 6.5 NPC 系统

- 每名 NPC 有作息、常用地点、喜欢/不喜欢的礼物、支线事件。
- NPC 对话随季节、天气、好感、事件进度变化。
- 好感不应只是数值奖励，必须解锁人物故事与村庄变化。

### 6.6 修复系统

- 玩家消耗木材、石材、作物、金钱、NPC 支援来修复设施。
- 修复后带来地图变化、功能解锁、剧情线索。
- 修复目标是长线进度的核心。

### 6.7 隐藏秘密系统

秘密来自生活行为：

- 某个雨夜听见神社铃声。
- 信箱出现没有寄件人的旧信。
- 老屋储物间发现旧照片。
- NPC 在高好感后提到“以前也有人回来过”。
- 柿子树每年同一天掉下第一片叶子。

## 7. 无战斗替代设计

由于项目明确不做战斗，下列需求应转译：

| 常规游戏需求 | 《那座村庄》替代方案 |
|---|---|
| 怪物阻挡道路 | 倒下的树、塌方、迷雾、被遗忘的路标 |
| 战斗升级 | 工具升级、关系升级、家园升级、料理熟练度 |
| Boss | 大型修复目标、节日筹备、NPC 心结、神社谜题 |
| 掉落装备 | 采集、委托回礼、修复奖励、旧物发现 |
| 危险区域 | 需要灯笼、草鞋、雨衣、NPC 陪同才能进入 |
| 击败敌人 | 安抚动物、清理杂草、修好水路、完成供奉 |

## 8. 经济与进度原则

- 金钱是工具，不是唯一目标。
- 不鼓励玩家只刷最高收益作物。
- 资源用途要分散：卖钱、料理、礼物、修复、供奉、图鉴。
- 高收益不应压倒情感选择。
- 每个季节至少有 3 条可行生活路线：种田、采集料理、社交修复。

---

## 9. 用户体验原则

- UI 文字简短、温柔、清楚。
- 失败提示不责备玩家。
- 关键任务可追踪，但不过度指引。
- 玩家可以慢慢玩，不会错过主线。
- 季节事件错过后下一年可再触发。
- 重要 NPC 事件不放在极难条件后。

---

## 10. 项目不做清单

MVP 与正式版都不做：

- 战斗。
- 联机 PVP。
- 随机地牢。
- 装备系统。
- 复杂股市经济。
- 重度自动化工厂。
- 高压饥饿/口渴/疾病系统。
- 需要大量反应速度的小游戏。
- 直接模仿任何现有游戏的地图或角色。

---

## 11. 成功标准

垂直切片成功时，玩家应能在 30 到 60 分钟内感受到：

1. 这个村庄适合慢慢待着。
2. 每天都有小事可做。
3. 种田、拜访、采集、修复之间有关联。
4. 村民不像功能按钮。
5. 美术风格统一且像游戏资产。
6. 背后似乎有秘密，但不恐怖、不压迫。
