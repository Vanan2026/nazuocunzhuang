# 09 — MVP 路线图与开发 Backlog

版本：v1.0  
用途：给 Codex 分阶段执行，不一次性做完整游戏。

---

## 1. 开发策略

先做“可玩的 30 分钟垂直切片”，再扩内容。

不要先做：

- 全四季。
- 全 NPC。
- 全料理。
- 全地图。
- 完整剧情 CG。

先做：

- 一天循环。
- 一块庭院。
- 几块农田。
- 两三个 NPC。
- 一条修复目标。
- 一条神秘传闻。

---

## 2. 里程碑总览

| 阶段 | 名称 | 目标 |
|---|---|---|
| M0 | 项目骨架 | Godot 目录、autoload、数据加载、主场景 |
| M1 | 基础操作 | 玩家移动、相机、交互、HUD |
| M2 | 时间生活 | 日期、时间、天气、睡觉、跨日 |
| M3 | 农田背包 | 地块、种子、浇水、成长、收获、背包 |
| M4 | NPC 对话 | NPC、对话、好感、送礼 |
| M5 | 修复系统 | 旧水井修复、视觉切换、解锁功能 |
| M6 | 内容垂直切片 | 6 NPC、8 作物、10 料理、10 事件 |
| M7 | 美术统一 | 按圣经替换占位图，完成 UI 风格 |
| M8 | 保存与打磨 | 存读档、菜单、音效、缺陷修复 |

---

## 3. M0 — 项目骨架

### 目标

建立可运行工程骨架。

### 任务

- 创建推荐目录。
- 建立 autoload 脚本。
- 建立 DataRegistry。
- 加载 items/crops/npcs/dialogues JSON。
- 创建 Main.tscn 和 WorldRoot.tscn。
- 添加基础 UI HUD 占位。

### 验收

- 项目可打开。
- 主场景可运行。
- 控制台打印已加载数据数量。
- 没有战斗相关类名或字段。

---

## 4. M1 — 基础操作

### 目标

玩家能在庭院中移动和交互。

### 任务

- Player.tscn。
- CharacterBody2D 移动。
- 相机跟随。
- InteractionArea。
- Interactable 基类。
- 门/信箱/公告板占位交互。

### 验收

- 玩家可移动。
- 接近对象显示交互提示。
- 按键触发交互文本。

---

## 5. M2 — 时间生活

### 目标

形成一天循环。

### 任务

- TimeManager。
- WeatherManager。
- HUD 显示日期、时间、天气。
- 床交互：睡觉进入下一天。
- 第二天天气生成。
- day_started/day_ended signal。

### 验收

- 时间流逝。
- 睡觉后日期增加。
- 天气变化影响 HUD。

---

## 6. M3 — 农田与背包

### 目标

玩家能种、浇、收。

### 任务

- FarmPlot。
- 种子物品。
- 浇水工具。
- 作物成长结算。
- InventoryManager。
- 背包 UI 初版。
- 雨天自动浇水。

### 验收

```text
开垦 → 播种 → 浇水 → 睡觉 → 成长 → 收获 → 背包增加作物
```

---

## 7. M4 — NPC 与关系

### 目标

NPC 具有基本生活感。

### 任务

- NPC.tscn。
- DialogueManager。
- 对话框 UI。
- NPC 日常对话。
- 好感值。
- 送礼接口。
- 每日首次对话加好感。

### 验收

- 至少 3 个 NPC 可对话。
- 对话受天气/季节影响。
- 送礼能改变好感。

---

## 8. M5 — 修复系统

### 目标

玩家能修复旧水井并获得实际变化。

### 任务

- RestorationTarget。
- 读取 restoration_targets.json。
- 检查材料。
- 扣除材料。
- 设置修复 flag。
- 切换水井视觉。
- 解锁庭院水源或传闻。

### 验收

- 材料不足显示需求。
- 材料足够可修复。
- 修复后不能重复扣材料。
- 修复状态保存。

## 10. M7 — 美术统一

### 目标

把原型占位图替换为统一治愈绘本风资产。

### 任务

- 主角基础动作。
- 6 名 NPC 头像与站立图。
- 庭院 tile。
- 作物 8 种 x 4 阶段。
- 道具 30 个。
- UI 基础包。
- 天气图标。

### 验收

- 所有资产符合命名。
- 缩小后可读。
- 角色不融入背景。
- UI 和场景同风格。

---

## 11. M8 — 保存与打磨

### 目标

垂直切片可稳定游玩。

### 任务

- SaveManager 完整保存。
- 读档菜单。
- 音效占位。
- 背景音乐占位。
- 设置菜单。
- 错误提示。
- 修 bug。

### 验收

- 退出重进后状态正确。
- 农田、背包、好感、修复状态不丢。
- 无明显阻断 bug。
