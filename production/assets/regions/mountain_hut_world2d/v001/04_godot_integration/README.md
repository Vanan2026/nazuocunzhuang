# MountainHut Godot Integration Boundary v001

No MountainHut World2D v001 runtime replacement is allowed during this art-prep phase.

## Allowed Now

- Static validation of package, seam brief, layout lock, layer contract, and review gate.
- Future source-image review against Village east continuity.
- Future review-only screenshot harness work after source/layers exist.

## Not Allowed Yet

- Replacing active `OutdoorWorld` generated MountainHut textures.
- Copying package layers into runtime paths.
- Setting `runtime_replacement=true`.
- Setting `launch_quality_approved=true`.

## Required Before Runtime Replacement

1. Human visual review accepts `mountain_hut_painted_source`.
2. Layers are exported from that same accepted source on the full canvas.
3. Layer review confirms no cropped/sticker-like structural patches.
4. Godot screenshot review shows the Village east edge and MountainHut west edge together.
