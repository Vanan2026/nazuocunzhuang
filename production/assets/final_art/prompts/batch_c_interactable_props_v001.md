# Batch C - HomeArea Interactable Props Prompt Pack v001

## Shared Style Lock
Create 2D game-ready transparent PNG assets for a non-combat cozy countryside life simulation game. Warm low-saturation rural storybook style, fixed top-down 3/4 perspective, soft hand-painted texture, gentle dark-brown outline, clear silhouette, large readable shapes, suitable for direct import into Godot. No text, no watermark, no characters, no weapons, no combat elements, no horror, no neon, no copied named game or animation style.

## Output Rules
- Transparent PNG.
- Keep each prop centered with enough transparent padding.
- Anchor expectation: bottom center unless otherwise noted.
- Visual scale must fit the `Region_HomeArea` 6144x4096 scene and protagonist frame 192x288.
- Props must be readable at gameplay zoom, not only in full resolution.
