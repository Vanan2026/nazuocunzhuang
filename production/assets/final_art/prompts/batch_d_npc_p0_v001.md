# Batch D - NPC P0 Prompt Pack v001

## Shared Sprite Style Lock
Create game-ready 2D NPC sprites for a non-combat cozy countryside life simulation game. Fixed top-down 3/4 perspective, warm low-saturation rural storybook style, 3.5 to 4-head body proportion, slightly large head, simple rounded hands and feet, clear silhouette, soft dark-brown outline, minimal clothing folds, transparent background, readable at 128x128. No weapons, no armor, no fantasy combat styling, no text, no watermark, no copied named game or animation style.

## Shared Portrait Style Lock
Create square 2D dialogue portraits for the same NPCs. Warm low-saturation storybook style, simple readable face, gentle dark-brown line, calm rural atmosphere, plain soft background or transparent edge-safe composition, no dramatic lighting, no text, no watermark.

## Acceptance
- Sprite identity must still be readable at 128x128 and 50% scale.
- Portraits must clearly belong to the same character as the sprite.
- No combat, weapon, armor, monster, damage, or high-pressure survival cues.
- Use stable character color accents so NPCs remain distinguishable in the yard.
