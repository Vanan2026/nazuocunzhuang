# Autoload Managers

Reserved for global managers such as GameState, EventBus, TimeManager, WeatherManager, DataRegistry, InventoryManager, RelationshipManager, QuestManager, DialogueManager, SaveManager, and SceneRouter.

Do not add combat, HP, damage, weapon, monster, or loot-drop state here.

Task 002 created script skeletons only. They are not registered in `project.godot` yet; registration should happen only after the new `game/` runtime path is ready to use them.
